# Vendored agent stacks

These Claude Code subagent definitions are vendored from
[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT licensed,
see `LICENSE` in this directory).

Only the divisions relevant to this project were pulled in: `engineering-*`, `testing-*`,
`security-*`, `finance-*`, `product-*`, `project-management-*`. The full library has ~280
agents across many unrelated domains (academic, marketing, game-development, healthcare,
etc.) — see the source repo if you need one of those.

Activate one in a session by name, e.g. "Activate Backend Architect" or "Use the Reality
Checker agent to verify this feature."
